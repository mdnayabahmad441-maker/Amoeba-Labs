# Phase 15: Weekly CEO Report

The Weekly CEO Report calculates one operational summary for the current week, previous week, or any selected week.

It covers sales, finance, delivery, and founder execution, followed by:

- Biggest pipeline bottleneck
- Five leads requiring immediate attention
- Three overdue financial actions
- Three delivery risks
- Next week’s top three priorities
- Loss reasons

The report uses existing leads, activities, calendar events, proposals, invoices, payments, expenses, projects, milestones, field visits, follow-ups, Today actions, and project-profitability data.

Print / Save PDF uses the browser’s print workflow and a print-friendly layout, avoiding a second PDF rendering implementation.

Content revenue is attributed only when a won lead’s source explicitly contains `content`; the report does not invent attribution.

No database migration is required for Phase 15. Earlier activity, field-visit, and profitability migrations must be applied for their respective metrics.
