# WhatsApp Follow-Up Setup

The portal now uses the WhatsApp Business app handoff flow.

When you click WhatsApp on a lead or client:

1. The portal prepares the selected message.
2. It opens WhatsApp or WhatsApp Business with the chat and message filled.
3. You press Send manually in WhatsApp.
4. The portal logs a WhatsApp follow-up entry.

This does not need Meta Cloud API tokens, phone number IDs, webhooks, or approved templates.

Phone numbers saved as 10-digit Indian numbers are opened with the `91` country code automatically.
